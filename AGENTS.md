# AGENTS

Este repositório é Spec-Driven Development.

1. Leia `specs/constitution.md` antes de mudar comportamento.
2. Feature nova começa em `specs/<id>-<nome>/{spec,plan,tasks}.md`.
3. Se o código precisar divergir, atualize a spec primeiro.
4. Offline-first: SQLite no device é a fonte da verdade da UI.
5. Native: Turbo Modules + New Architecture. Expo Go não é alvo.
